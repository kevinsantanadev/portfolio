## Executando localmente

Você precisa ter o [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/kevinsantanadev/portfolio.git
cd portfolio
npm install
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000) no navegador.
